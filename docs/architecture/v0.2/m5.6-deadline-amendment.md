# M5.6 deadline amendment (frozen with M5.7)

Status: Architecture amendment
Applies to: V0.2 / M5.6 as closed by M5.7
Does not revert M5.6. Supersedes the M5.6 wording that every
Scheduler-facing adapter call returns before the Instant endpoint even
when a host kernel primitive never returns, and the wording that
`collect_outcome` is Task ACK/NACK proof authority.

## Absolute deadline

The deadline is absolute for every **adapter-controlled userspace**
stage, wait, retry, and cleanup. After any primitive returns, the same
deadline MUST be re-qualified before the next blocking or side-effecting
stage. Runtime `ResolvedAdapterBinding` re-qualifies again before
admitting returned evidence.

OS/kernel progress is an explicit execution assumption: an
uninterruptible host syscall is outside the in-process liveness
guarantee. Detached watchdog threads that let Scheduler return while the
adapter keeps running are still forbidden.

Late `AdapterError` MUST prefer `runtime_handle_hint` learned during the
call over the operation's input handle.

## Collect is not Task Result authority

`ExecutionAdapter::collect_outcome` reports physical environment end.
It MUST NOT be interpreted as Task ACK/NACK proof. Task Result belongs
to a separate Worker data plane.

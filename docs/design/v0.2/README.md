# V0.2 design landing zone

Status: Index
Canonical path: docs/design/v0.2/README.md

This directory is the landing zone for **future** V0.2 / RIIR design documents
only.

V0.2 is expected to cover a future Rust implementation and any semantic
architecture evolution. The repository-normalization change does **not**
reconstruct V0.2 from scattered assumptions. A later dedicated design task
lands those documents.

Do not put implementation code here. Do not put crate-layout or RIIR drafts in
`docs/development/` or `docs/decisions/`.

Until that design task lands documents:

- Current normative V0.1 contract: [docs/specs/v0.1.md](../../specs/v0.1.md)
- Language-independent invariants: [docs/architecture/overview.md](../../architecture/overview.md)
